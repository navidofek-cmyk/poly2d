# OpenFOAM case — NACA 0012 (poly2d mesh)

Ready-to-run steady incompressible RANS (k-ω SST) case around the NACA 0012
generated by **poly2d**. Target: OpenFOAM (foundation) **v11+ / v14** modular
solver `foamRun` (`incompressibleFluid`).

## Geometry / flow
* chord `c = 1 m`, circular farfield `⌀ 10 m`, angle of attack **10°**
  (baked into the geometry — freestream is along +x),
* `U∞ = 30 m/s`, `ν = 1.5e-5 m²/s` → `Re = 2·10⁶`,
* 2D: one cell in `z`, `frontAndBack` is an `empty` patch.

## Patches (match the mesh written by poly2d)
| patch | type | BC |
|-------|------|----|
| `farfield` | patch | freestream (auto in/outflow) |
| `airfoil` | wall | no-slip + wall functions |
| `frontAndBack` | empty | 2D |

## Run
```bash
./Allrun      # builds poly2d, generates + imports the mesh, runs foamRun
./Allclean    # reset
```
`Allrun` calls the mesher (`../../build/poly2d airfoil`) and copies
`out/airfoil/constant/polyMesh` here, so the mesh is **not** committed — it is
regenerated. Force coefficients (Cl, Cd) are written by the `forceCoeffs`
function object in `system/controlDict`.

## Notes
* For **ESI OpenFOAM** (`simpleFoam`): rename `constant/physicalProperties` →
  `transportProperties`, `constant/momentumTransport` → `turbulenceProperties`,
  set `application simpleFoam;` in `controlDict`, and run `simpleFoam`. The field
  files and BCs are otherwise identical.
* First cell height 0.005 m at this Re gives a high-y⁺ mesh, hence wall
  functions. For a low-y⁺ (wall-resolved) setup, shrink `firstHeight` in
  `caseAirfoil()` and switch to low-Re wall treatment.
